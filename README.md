# sipemu/homebrew-tap

Homebrew formulae for [dbt-lineage](https://github.com/sipemu/dbt-lineage-viewer).

```sh
brew install sipemu/tap/dbt-lineage
```

`Formula/dbt-lineage.rb` installs the pre-built release binaries (macOS and Linux, Intel and ARM). It is regenerated every 6 hours from the latest release by `.github/workflows/update.yml`; run that workflow manually to update right after a release.
